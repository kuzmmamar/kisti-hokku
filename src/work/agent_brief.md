## Задача
Ты подбираешь классические японские хокку для приложения, где хокку раскладываются по 72 микросезонам японского календаря (七十二候 ко). Каждое найденное хокку должно содержать само слово микросезона или очень близкий к нему сезонный образ. Например, для «Выпадает первый иней» в стихе должно быть 霜 (иней). Для «Прилетают ласточки» — 燕/つばめ.

## Жёсткие требования
1. **Только авторы, умершие до 1929 года**, чтобы стихи были в общественном достоянии. Предпочтительный порядок: Басё, Бусон, Исса, Масаока Сики, Тиё-ни, ученики Басё (Кикаку, Рансэцу, Кёрай, Дзёсо, Бонтё, Сора, Ясуи, Ёсо и др.), Оницура, Гонсуй, Тайги, Сёха, Кито, Нацумэ Сосэки (умер в 1916). Современных поэтов (Кёси, Сантока, Хакёку и т. п.) не брать.
2. **Текст оригинала проверь по японскому источнику в интернете.** Подходят японская Википедия, сайты с текстами хокку Басё, Бусона, Иссы (например, 芭蕉DB, 一茶 俳句 サイト, 蕪村 句集), школьные или академические страницы. Используй WebSearch и WebFetch, искать лучше по-японски. Не выдумывай и не восстанавливай по памяти без проверки. Если подлинность не подтверждается, ищи другое стихотворение. Для каждого стиха укажи URL, где ты видел текст.
3. **Не повторяй хокку, которые уже есть в приложении** (список ниже).
4. **Русский перевод — только свой**, дословный и простой. Его нельзя копировать из опубликованных русских переводов (Маркова, Брегель, Долин и др.): они защищены авторским правом.
5. Если подлинного стиха с точным словом не найти (бывают редкие темы вроде 半夏生 или 鶺鴒), возьми классический стих с ближайшим образом того же времени года. В поле note честно объясни связь.

## Формат ответа
Ответь ТОЛЬКО JSON-массивом (без пояснений вокруг). На каждый стих — объект:
```
{"ko":52,"a":"Басё","y":"1690","j":["葛の葉の","面見せけり","今朝の霜"],"k":["くずのはの","おもてみせけり","けさのしも"],
 "c":"кудзу-но ха-но / омотэ мисэ кэри / кэса-но симо",
 "t":"Листья кудзу / показали изнанку — / утренний иней.",
 "hj":"葛の葉の/面見せ[けり]/今朝の{霜}","hk":"くずのはの/おもてみせ[けり]/けさの{しも}","hc":"кудзу-но ха-но / омотэ мисэ [кэри] / кэса-но {симо}","ht":"Листья кудзу / показали изнанку[ —] / утренний {иней}.",
 "w":"霜","src":"https://...","note":"霜 — иней, прямо по теме микросезона"}
```
Поля:
- **j** — 3 строки оригинала в исторической орфографии, как в источнике.
- **k** — те же 3 строки хираганой, со звуками, как их читают.
- **c** — кириллическая транскрипция по Поливанову. Долгие гласные обозначай двоеточием: то:гэ, хо:рю:дзи. は-частица → ва, を → о, へ → э. Строки разделяй « / ».
- **t** — перевод, строки разделяй « / ».
- **y** — год, если известен, иначе "".
- **hj, hk, hc, ht** — та же строка с разметкой:
  - `{…}` — сезонное слово;
  - `[…]` — режущее слово или знак разрыва (や, かな, けり, ぞ, なり, ぬ, らん…; в переводе — точка, тире, двоеточие, восклицательный знак).
  - Всё до первого `[…]` или `|` — первый образ, всё после — второй.
  - Если режущего слова на границе образов нет, поставь `|` там, где образы меняются.
  - Если かな/けり стоит в самом конце, а образы делятся раньше, поставь и `|` на границе, и `[かな]` в конце.
  - Без разметки строка должна совпадать символ в символ: hj без скобок и с «/» вместо разрывов строк = j, hk = k, hc = c, ht = t.

## Примеры разметки из приложения
- 古池[や]/{蛙}飛びこむ/水の音 · фуру икэ [я] / {кавадзу} тобикому / мидзу но ото · Старый пруд[.] / Прыгает {лягушка} — / звук воды.
- 野ざらしを|/心に風の/{しむ身}[かな] · нодзараси о| / кокоро ни кадзэ но / {симу ми} [кана]
- 旅に病んで|/夢は{枯野}を/かけ廻る
