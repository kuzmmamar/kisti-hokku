КИСТЬ И ХОККУ — установка на iPhone

Приложение нужно один раз выложить в интернет (бесплатно), открыть в Safari
и добавить на экран «Домой». После первого запуска оно работает без интернета.

ШАГ 1. Выложить папку (выберите один способ)

  Способ А — Netlify (проще всего, с компьютера)
  1. Распакуйте архив. Внутри будет папка с файлами index.html, sw.js и т. д.
  2. Откройте https://app.netlify.com/drop и войдите (бесплатный аккаунт).
  3. Перетащите папку целиком в окно браузера.
  4. Через несколько секунд появится адрес вида https://что-то.netlify.app —
     это и есть ваше приложение. В настройках сайта имя можно поменять.

  Способ Б — GitHub Pages
  1. На github.com создайте новый публичный репозиторий, например kisti-hokku.
  2. «Add file» → «Upload files» → перетащите СОДЕРЖИМОЕ папки (не саму папку).
     Нажмите «Commit changes».
  3. Settings → Pages → Source: «Deploy from a branch», ветка main, папка / (root).
  4. Через минуту адрес будет https://ВАШ-ЛОГИН.github.io/kisti-hokku/

ШАГ 2. Установить на iPhone
  1. Откройте этот адрес именно в Safari.
  2. Подождите пару секунд, пока страница загрузится полностью (так всё сохранится для работы офлайн).
  3. Кнопка «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
  4. Запускайте с иконки 筆. Приложение откроется на весь экран.

ВАЖНО ПРО ПРОГРЕСС
  • Прогресс хранится внутри приложения на телефоне. Если удалить иконку, он пропадёт.
  • Внизу экрана «Путь» есть кнопка «Резервная копия»: скопируйте код
    и сохраните его в Заметках. Тем же кодом можно перенести прогресс на iPad.

ОБНОВЛЕНИЯ
  Если я пришлю новую версию — замените файлы на хостинге
  и в sw.js увеличьте VERSION (kisti-v1 → kisti-v2). Приложение подхватит
  новую версию при следующем запуске с интернетом.
